# Portfolio — Tanh Mouele

Portfolio personnel construit avec React et Vite, orienté informatique, bases de données et systèmes connectés.

## Démarrer le projet

Prérequis : Node.js installé.

```bash
npm install
npm run dev
```

Vite affichera une adresse locale dans le terminal, généralement `http://localhost:5173`.

## Vérifier la version de production

```bash
npm run build
npm run preview
```

## Avant de publier

1. Remplacer l'adresse e-mail d'exemple dans `src/App.jsx`.
2. Ajouter les vrais liens GitHub et LinkedIn, si disponibles.
3. Vérifier chaque description de projet et préciser ce qui est terminé, en cours ou simulé.
4. Ajouter uniquement des captures d'écran que tu as le droit de publier.
5. Ne jamais publier de mots de passe, clés API, fichiers `.env`, données clients ou informations internes d'OFIS.
6. Tester le site sur téléphone et ordinateur.

## Déploiement

Le projet peut être publié sur Vercel ou Netlify en important le dépôt GitHub. Commande de build : `npm run build`. Dossier de sortie : `dist`.

Les contenus de projets sont volontairement prudents : mets-les à jour selon l'état réel du travail avant d'envoyer le lien à un recruteur.
